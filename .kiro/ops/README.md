# Operations Documentation

This directory contains operational documentation, deployment configurations, and team management resources for the KiroTax AI platform.

## Directory Structure

```
ops/
├── team_roles/          # Team member responsibilities and task assignments
├── prs/                 # Pull request templates and review guidelines
├── deployment/          # Deployment scripts and configurations
└── terraform/           # Infrastructure as Code (IaC) configurations
```

## Purpose

- **Team Roles**: Define clear responsibilities and task ownership
- **PRs**: Standardize code review and merge processes
- **Deployment**: Automate and document deployment procedures
- **Terraform**: Manage cloud infrastructure declaratively
